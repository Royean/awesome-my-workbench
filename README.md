# 知衡 · 个人健康工作台

一个参考 TREK 结构化管理与助手交互的本地单用户健康后台，整合就医、锻炼、饮食、监测、计划和资料。

## 运行

需要 Node.js 24 或更新版本，无需安装依赖。

```sh
npm start
```

也可双击 `start.command` 启动。在此电脑打开 http://localhost:3100 。可通过 `PORT` 更换端口。当前电脑可直接使用：

```sh
/opt/homebrew/opt/node@24/bin/node server.mjs
```

## 已实现

- 健康总览：近期数值、分类趋势、今日计划、跨模块时间线、快捷记录。
- 就医：机构、科室、日期、状态、就诊记录与关联附件。
- 锻炼：运动类型、时长、日期、感受与累计时长。
- 饮食：餐次、时间、餐食与备注。
- 监测：体重、血压（双值）、睡眠、血糖、心率；按7/14/30天查看同类同单位趋势。
- 计划：分类、日期、时间、完成与取消完成。
- 资料：PDF、图片、TXT上传与下载，单文件10MB，关联就医；未实现OCR。
- 所有记录可编辑、搜索和按日期筛选；删除确认后可在12秒内撤销。
- 示例与个人空间分离，设置与数据持久化；JSON导出包括记录和文件元数据，不包括附件字节。
- 健康助手入口与本地统计摘要。**未连接AI模型，不提供模拟AI答复；无远端MCP服务。**

## 数据位置与边界

SQLite位于 `data/health.sqlite`，原始附件位于 `data/uploads/`。不自动读取既有私人健康仓库或Drive，也不覆盖它们。个人空间初始为空，示例数值均为虚构。备份时停止服务并复制整个 `data/` 目录（若热备份则需使用SQLite备份机制）。删除资料只移除界面记录，原始附件保留在本机，以支持撤销；此版本不作自动文件清理。

当前仅绑定 `127.0.0.1`，适合个人本机试用，无账户权限、设备同步、消息通知或远程访问配置。计划是应用内待办，不会发送系统通知。记录仅用于整理与回顾，不做自动诊断、处方或医疗阈值判定。
