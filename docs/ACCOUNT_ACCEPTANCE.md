## 结论

本机独立验收通过：串行自动回归 **47/47**；真实 Node/SQLite 后端与 Chrome 手机视口交互 **11 组通过**。未发现新的阻断缺陷。此结论限于本机产物与浏览器视口仿真；腾讯云部署、HTTPS 运行和实体手机仍有待验证项，不能据此宣称生产全项通过。

## 环境与方法

- macOS，Node `24.20.0`，本机 Chrome headless / Playwright，360×844 与390×844，触控/移动视口。
- 真实服务监听独立回环端口3298，`AUTH_REQUIRED=1`、`NODE_ENV=test`、精确 `APP_ORIGIN`；数据位于独立临时目录，结束删除。未操作3100服务及真实用户数据。
- 浏览器路径均使用真实 API 与 SQLite；仅在连接恢复用例主动阻断一次 `/api/auth/me` 请求，以产生真实网络失败，不模拟业务响应。
- 两用户和第二设备使用独立浏览器上下文；管理员通过CLI初始化，成员由管理员界面生成邀请，再由成员真实激活。密码运行时随机生成，不写日志；邀请链接只在测试进程内使用。
- 脚本 `tests/account-acceptance.mjs` 需要 Playwright 与本机 Chrome，不属于默认 `*.test.mjs` 回归发现范围。可执行 `npm install --no-save playwright` 后运行；已有外部安装时可用 `PLAYWRIGHT_MODULE` 指定其模块URL。

执行命令：

```sh
node --test --test-concurrency=1 tests/*.test.mjs
node tests/account-acceptance.mjs
```
