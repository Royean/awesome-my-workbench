# 资产工作台与独立主题

原 finance 工作台显示名改为「资产」，ID/type 保留 finance，已有备忘、待办和个人/示例数据空间不搬动。默认砖红 #A65343；健康保留绿色。所有工作台均可在「我的 → 工作台主题色」选择色板或自定义六位HEX，按账号与工作台保存在服务器，切换后分别生效；按钮前景按对比度派生。

## 管理功能与口径

侧栏保留总览、金融资产、固定资产、流水、事项、资料六个主入口，「我的」固定在底部。金融资产与固定资产分别维护；账户、负债在金融资产页内管理，历史快照和全部资产明细在总览页内查看，备忘归入资料。事项集中展示最近五条未完成待办、还款安排与到期续费，可进入全部待办。手机底部保留总览、金融、固定、事项、我的，流水与资料通过模块导航进入，新增操作位于页头「记录」。原有路由和记录类型保持兼容。可新增编辑记录、搜索及分类/账户筛选、查看来源、软删除与最近删除恢复、上传及预览安全原件、导出当前空间。金融功能是记账与归档，不连接银行或券商交易通道，不会因记录流水自动重算/重放持仓。

资产以原币种分组，不自动混加外币；账户余额只有明确勾选 includeInTotal 才计入，含持仓的账户总额不能再次累加。未知估值保留缺失，不用零元替代；待核对持仓估值单列，已结束项目不计当前已确认金额。存在未核实负债时不声称已得实际净资产。只有来源有可靠成本时才计算账本盈亏，缺失或仅估算成本的导入保留原说明，不制造真实收益。

历史快照、交易日期、余额日期、价格日期和资料日期分别保留。未来 active 资产/负债确认日期不能直接计入当前，须以pending记录计划；未来到期日可正常填写。历史快照不重复计入当前总额。服务器、域名等费用保留为费用/维护信息，没有独立市场估值时不把续费价格作为资产价值。

## 接口与隐私

新增 items 类型 asset_account、asset_holding、asset_liability、asset_transaction、asset_snapshot，仅资产工作台可用；MCP create_record/update_record/list_records 同步支持，list_records可按externalId精确查重。externalId在同类型同空间内包含最近删除防重，恢复也检查重复。资产关联只能引用同空间账户/持仓。浏览器财务写入、原件上传及主题PATCH要求期望用户头匹配实际会话，避免其他标签切账号后旧表单串写；MCP仍按Bearer认证及读体后复核。

资料支持PDF、图片和TXT，单份10MiB，按账号与空间私有保存。HTML邮件字节以.html.txt安全文字展示，不执行活动HTML。原件来源URL、摘要和导入外部编号用于追溯，不将私有数据或凭据写入公开代码。财务接口与健康、CGM数据仍隔离，原有备份脚本继续涵盖SQLite及上传原件。

## 数据导入与验收

用户已明确授权从既有私人GitHub和GoogleDrive导入，原来源保持不变。导入前在仓库外核对来源提交/文件摘要、日期与口径，剔除凭据和程序，区分已发生交易与计划；通过MCP进入个人资产空间，保留幂等外部编号并读回验证。加密或不支持的档案保留来源与原因，不绕过密码或把未读内容算作已导入。

实际执行：/root协调、私有导入、集成与发布；/root/assets_backend后端；/root/assets_ui界面；/root/assets_sources源核对；/root/assets_review独立评审；/root/assets_acceptance独立UI验收。精确提交、回归结果、部署与导入核验见Issue #36及关联PR。公开验收夹具与截图只使用虚构数据，真实财务清单保存在用户私有目录和个人工作台。
