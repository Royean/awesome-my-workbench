# CGM 平台连接与自动同步

入口：健康工作台的「健康监测」以及「设置与连接」。第一版适配硅基轻享，使用用户提供的接入实践中描述的非官方云端接口；其他 CGM 品牌暂未接入，不表示已有通用厂商授权。

用户选择平台，填写平台手机号和密码，并勾选持续同步授权。首次登录并成功读取云端后才保存连接，每五分钟由服务器继续同步；原厂手机 App 仍须正常上传探头数据。厂商云端可读取的窗口通常为最近七天，已同步的数据在本工作台持续保存。数据滞后、登录失效、暂停或平台错误会明确显示，不能把厂商数据断流标为当前正常。

## 数据与账号

- 凭据和平台token使用AES-256-GCM加密，服务器数据目录 cgm.key 保存32字节密钥，权限0600。浏览器只返回脱敏账号和安全状态；密码不存浏览器持久存储，也不通过MCP或通用记录导出。
- CGM连接只允许已登录会话管理，个人访问令牌不支持。限制个人健康空间；期望用户头与真实会话不一致时，在调用外部平台之前拒绝，防止旧页面切换账号后串写。
- 点保存在专用 cgm_readings 表，不写入通用 items。按工作台空间、平台、账号指纹与毫秒时间戳去重；允许乱序补传及相同时间戳更正。更换同平台账号前需要断开，历史按账号分开。
- 页面以北京时间自然日绘图，横轴为真实时间；无数据时不造曲线，缺失区间不补点。均值、最小和最大值只是已收集点的描述，不等同诊断、TIR或治疗建议。
- 可见页面每分钟刷新；隐藏、离开卡片、填写凭据或写操作中暂停刷新。即使页面没有重新收到服务器响应，也按当前时间计算已知读数是否超过30分钟未更新。

## 后台行为

每30秒扫描到期连接，正常间隔五分钟，重启后继续到期任务。提前五分钟更新即将失效token；HTTP401或HTTP200/body.code401只自动重新登录一次，仍失败则要求用户重新连接。请求固定HTTPS域名、不跟随重定向，15秒超时、5MiB响应上限；失败指数退避，认证错误停止后台重试。暂停、断开、停用工作台账号及会话撤销在写回前复核，避免已经排队的后台请求恢复被用户关闭的连接。

断开会删除保存的连接凭据，保留已同步读数；不会替用户删除原厂平台账号或数据。平台密码变更后可重新连接。此版本不提供手机推送、原厂报警替代或蓝牙直连。

## 备份与恢复

scripts/backup.mjs 在在线SQLite快照之后复制上传文件和 cgm.key；连接或历史读数存在而密钥丢失时拒绝生成不可恢复的备份。恢复时须一起恢复 health.sqlite、uploads 与 cgm.key，并保持服务账号可读、目录0700及密钥0600。密钥不可通过公开仓库、下载接口或日志交付。已有连接或历史而密钥丢失时系统拒绝生成新密钥，管理员须恢复原密钥；历史读数本身仍可读。
