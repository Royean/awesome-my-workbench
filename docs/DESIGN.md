# 知衡界面设计与审查

角色：UI/UX /root/health_design；产品协调与实现 /root。

## 信息架构

固定侧栏整合健康总览、就医、锻炼、饮食、监测、计划、资料及设置。示例/个人空间持续可见。
总览按近期指标、今日计划、同类趋势、跨模块时间线和快捷记录组织，窄屏优先展示今日计划。
统一抽屉承担新增/编辑；总览添加入口先选择记录类型。删除需确认并提供12秒撤销。

## 视觉

深青侧栏，米白背景，白色细边卡片；青绿为主色，杏色、蓝灰、暖粉区分记录类型。
图表使用真实已保存数值；不设置诊断阈值或健康总分。空间内示例数据明确标注为虚构。
图标为项目内SVG，不依赖外部网络资源。
