# 报告文字、原件与缩略图

入口：就诊管理 → 就诊报告，或打开某次就诊 → 报告。点击报告标题或「查看文字」打开已保存的报告内容；点击缩略图或「查看原件」查看关联 PDF/图片。原件查看页支持「返回报告文字」。资料档案中点击名称、缩略图或「预览」直接打开原件。

PDF 显示首页缩略图，预览支持上一页/下一页、输入页码、缩小/放大和下载；图片显示真实缩略图，原件支持缩放、适合窗口和下载；TXT 直接显示纯文字，不执行 HTML。无法显示/原件缺失有错误提示和下载入口；没有原件保留占位，不伪造缩略图。未提供 OCR 或自动报告解读。

缩略图仅在接近可视范围时读取，最多并发 2 个，图片缩至小 canvas，PDF 画布限制 16MP/8192 边。页面切换、关闭、账号/空间变化会取消任务、撤销 blob URL 并清除旧画布、文字、音频。BFCache 返回重新生成可视缩略图。私有原件沿用原账号/空间权限与 no-store，不写入本地持久缓存、不发送到第三方。

PDF 渲染器本地托管于 public/vendor/pdfjs/6.4.299/，来自官方 npm registry 的 pdfjs-dist 6.4.299，发布包 SHA512 与 npm 元数据比对通过。LICENSE、字体/CMap/WASM 原始许可证一并保留。公共版本化代码可缓存，不包含私人报告。
