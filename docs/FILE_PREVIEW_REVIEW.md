# 原件预览独立代码评审

日期：2026-11-01。基线：70b4fcb；评审当前工作区 `public/file-preview.js`、`public/app.js`、`public/medical.js`、样式和服务端 MIME/CSP 改动，以及现有账号、文件下载、构建生命周期依赖。本记录不代表用户审批或生产发布批准。

## 检查结论

当前已核查的原件预览主路径未发现文件跨账号或跨空间读取缺口。原件仍通过既有受鉴权的同源文件接口取得；PDF.js、worker、CMaps、字体、WASM 均使用同源、带版本路径，不引入 CDN。新增静态 MIME 和 CSP 允许本地模块 worker、WASM 编译和内存字体，未允许任意 JavaScript eval。

缩略图按 IntersectionObserver 延迟加载，最多两项同时运行；图片转为最大 200×240 的 canvas 后释放原图和对象 URL。PDF 原件按单页串行绘制，取消旧 render 并检查 revision，画布限制为约 16MP、最长边 8192。查看原件与报告手工文字保留独立入口。

## 已提出并复核的修复

- 原 401 仅显示普通预览失败；现触发全部预览清理及统一账号失效流程。
- 原销毁只处理图片与 canvas；现清空原件文字 DOM，暂停并移除音频来源，撤销对象 URL。
- 原缩略图保留完整解码大图；现转小 canvas 后释放原图。原 PDF 仅限制宽度；现限制总画布像素和最长边。
- 原缩略图错误分支可能访问不存在的占位标签；现有空值防护。
- 原个人空间快捷入口未走统一清理；现使用 setSpace。会话更换会关闭原件弹窗。BFCache 离页清理预览并关闭弹窗；恢复时先清空 items、settings、旧状态缓存并展示加载占位，再通过 load() 获取状态。loadInner() 检查 foreignOwner，401 走统一账号失效流程，验证通过后才重绘资料，避免先展示离页前的旧账号数据。此最终调整已作只读代码复核，无待修复建议。

已逐项检查 render 前、列表局部搜索和筛选前清理，关闭/替换弹窗清理，以及空间、工作台、账号变化时 cleanupAll。异步写回绑定原 DOM、缩略图 epoch 或 viewer identity，销毁后 AbortController 和身份检查阻止旧请求把内容注入新视图。预览模块未向 localStorage、IndexedDB 或服务端写入原件或缩略图缓存。
