# 资产总览重设计

2026-11-05。基于用户认可的 ImageGen 桌面稿，将多币种大卡片和资产长清单改为一个原币财务汇总、金融分布与历史变化、紧凑关注事项、金融/固定两块管理摘要。主线基准 `4152754`，实现与产品/界面整合 `/root`，独立验收 `/root/finance_nav_qa`，独立代码审查 `/root/finance_overview_review`。

## 确认范围

- 总览一处标题与记录按钮，收起重复问候栏和页内总览导航。其余工作台与金融/固定管理页保留原流程。
- 当前空间的人民币、港币、美元等原币可切换。其他币种以紧凑金额入口展示，不自动换汇或混加。
- 摘要展示已估值净额（有未知负债时改为已知资产估值）、资产、已记录负债与快照变化。无金额使用破折号；显式0元仍为0。资料日期显示记录估值范围，不标为实时更新。
- 分布仅计金融资产和明确勾选计入的现金账户余额。支持按类别、所属账户、原币查看，未关联账户单列；按币种不计算跨币种百分比。
- 金融与固定摘要仅展示当前币种。未知估值和待核对资产不加入已确认金额；续费费用不当作固定资产估值。其他分区资产保留单独提示，不静默丢失。
- 关注条聚合当前空间的未估值、待核实负债、待核对资产、近期到期、还款与待办；仅提供进入现有管理页的入口，不自动修改记录。

## 历史口径

仅使用同币种的历史净额快照。明确填写 `totalValue` 或同时有 `assetValue` 和 `liabilityValue` 才有可用净额。未来、无有效日期、待核对或已结束的数据不绘制；有两套金额口径时按界面两位小数比较，冲突则排除并提示。相差一分钱会被检出，普通浮点计算尾差不会制造冲突。

同币种同日一致净额合并成一个点；同日冲突的日期暂不绘制，保留核对入口。不用持仓的混合估值日期拼出当前历史点，不插补缺失月份。零/一次快照显示真实空态，提供记录入口；两次及以上以日期为X轴绘制净额，支持近6个月/近一年和可读数据表。顶部「快照变化」比较最近两个有效快照并注明日期，不能称作本月收益或投资收益。

## 验收条件

- FO-01：金额、币种、opt-in账户与缺失/待核对/已结束记录口径守恒，未知负债不产生实际净资产声明。
- FO-02：选币种、分布维度、时间范围均实际改变展示；账号/工作台/空间切换重置本地视图状态。
- FO-03：历史快照的重复、冲突、一分差额、未来、负净额、零值、缺口与期间过滤符合上述规则。
- FO-04：桌面与360px手机无横向溢出；键盘能操作选择器与分组按钮，图表有文本数据，主题变色保持可读。
- FO-05：示例与个人空间隔离，保留金融/固定/账户/负债/历史/流水/资料入口；展示不写数据库。

验证结果与限制分别记录在 `FINANCE_OVERVIEW_ACCEPTANCE.md` 和 `FINANCE_OVERVIEW_REVIEW.md`。本设计不包含资产记录重分类、数据迁移、汇率接入或新收益引擎。
