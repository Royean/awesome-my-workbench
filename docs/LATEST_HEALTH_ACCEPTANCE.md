| 场景 | 实际结果 |
| --- | --- |
| 真正空态 | 饮食、运动、就诊、报告显示无记录；体重显示无记录且没有范围外历史占位；今日饮水 0，无虚构数据 |
| 分类独立、历史 30 天、跨年 | 同时存在 6 条餐食，首页只显示日期时间最近的 1 条；历史就诊、运动、报告和各身体指标仍各自显示；完整年份日期可见 |
| 同日时间排序 | 同日 18:00 的 68.7kg 优先于 08:00 的 99.9kg；报告原件 14:00 优先于文字报告 13:00 |
| 未来观察与未来待办 | 未来餐食、就诊、运动、体重、水量和原件不作为历史最近记录或实际统计；未来待办正常保留 |
| 趋势范围外历史 | 近 14 天暂无体重记录时显示「最近一次：68.7 kg」和完整记录日期，保留明确的范围内无记录说明，不伪画趋势点 |
| 报告资料过滤 | 当天较新的「餐食附件」「药品图片」不挤掉历史原件；未来原件也不挤掉历史原件 |

| 今日用药 | 只有当日有效方案进入今日列表；过期和未来开始方案排除；昨天已服用记录不冒充今天完成，今天仍显示「记录已服用」动作 |
