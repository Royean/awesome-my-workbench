# 健康总览：保留最近记录

用户确认：健康记录频率不固定，总览每个分类应保留最近一次记录，显示实际记录日期；没有今天的数据不能清空已有历史，也不能把历史算进今天的统计。

开发及现有布局内的交互调整：开发工程师 `/root`；独立验收：测试验收工程师 `/root/todo_acceptance`。改动在独立工作树、基于最新主分支完成，原工作区未提交修改保留。

## 验收范围

- 饮食、就诊每类显示最近一条已到记录日期的历史记录，不受最近几天是否有数据影响；可查看全部记录和打开对应原记录。
- 运动继续展示近 7 天统计与柱形图，并增加最近一次实际记录，包括更久以前的运动。历史时长不会回填至近 7 天。
- 报告与资料显示最近一条报告文字或原件；餐食附件和药品图片不作为报告。点击进入对应报告或原件。
- 身体指标按指标类型保留最新值。日期标签区分今天、昨天和含年份的历史日期，可显示原记录时间；历史记录标注“今天还未记录”。
- 监测时间范围内没有记录但存在更早数据时，明确说明“近 N 天暂无记录”，附带最近一次的数值与真实日期；不把范围外数据画到当前时间轴上。
- 尚无记录的分类显示空状态；未来日期的观察值不作为最近历史，但未来待办继续按原有规则显示。
- 今日饮水、今日用药、今日运动及近 7 天运动均使用各自真实日期范围。原记录、API 和存储格式不变，不创建用户健康记录。
- 桌面及 360px 手机宽度均可阅读日期、数值和状态，无横向溢出。

## 实现和验证

`public/latest-health.js` 集中处理各类最近记录选择与日期标签；`public/app.js` 接入现有卡片；样式沿用健康总览的卡片布局，增加最近运动、报告和范围外监测的展示样式。
