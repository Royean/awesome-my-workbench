## 验收边界与遗留

- 本文件仅记录新增附件能力的独立验收；完整既有回归由主任务执行。
- 请求期间撤销测试证明部分正文发送后撤销令牌不会落库；客户端没有服务端认证阶段探针，因此不主张测定认证与撤销之间的精确调度时序。
- 没有进行文件内容解析器、病毒检测、恶意 PDF/图像内容检查；当前实现按受支持扩展名保存并核对字节完整性，这些检查不在本次接口约定范围。
- 未覆盖外部进程同时上传时的跨进程竞态，也未注入进程被强制终止、磁盘故障或 SQLite COMMIT 故障；已通过真实 SQLite UPDATE 故障验证关联事务回滚。
- 无阻断问题。测试仅新增 `tests/mcp-attachments.test.mjs` 与本文档，没有修改实现文件。
