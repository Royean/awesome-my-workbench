## 结论

## 发现与修复复核

- 原 Base64 重复分组正则对合法最大长度字符串抛出 `RangeError: Maximum call stack size exceeded`，已用 Node 24 内存假数据复现；现已改为线性字符检查、长度检查和编码往返比对。
- 原报告上传复用了包含音频的全局扩展名表；现已限制为 PDF、PNG、JPG/JPEG、WEBP、TXT。
- 原写文件后才标记清理所有权，部分写入失败可能留文件；现成功以 `wx` 打开后立即标记，在失败路径回滚并清理，文件描述符由 `finally` 关闭。
- 原提交后读盘生成返回值失败可能删除已提交文件；现元数据在提交前计算，提交后直接返回。
- 历史原件内容缺失原会使列表失败；现返回 `sha256:null`、`missing:true`。列表先截取请求条数再读取文件摘要，避免 limit 很小时仍读取全部原件。

同一空间内同文件名、日期、标题、备注、内容的上传重试复用现有记录；不同内容或元数据创建新记录，磁盘摘要重新计算。报告关联通过同一事务更新原件就诊归属和报告原件引用；重复同一关联不重写。
