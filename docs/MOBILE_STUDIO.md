# 手机端 Studio 界面

关联 Issue #60。基线：3a597ac。实现协调 `/root`；设计/独立代码复核 `/root/mobile_design_review`；独立验收 `/root/mobile_acceptance`。遵循私人角色库的软件开发协作规范。

用户希望手机端延续电脑端的灰白圆角 Bento 风格，并保持每个工作台的独立主题色。桌面已获用户认可，手机优化使用独立的 `studio-mobile.css`，最后进入现有确定性构建。

- 900px及以下采用16px页面边距、24px卡片圆角。顶栏将品牌说明与当前工作台分两行，提供数据空间和个人设置。首页增加日期及主题色入口。
- 底部导航成为保留系统安全区的浮动导航，列数取实际入口数。阅读的两个入口均分空间；选中入口用当前工作台主题底色，记录按钮保持在导航内部。
- 健康用成组快捷记录、浅主题色趋势卡及最近身体指标建立层级，近期数据与今日状态仍来自真实记录。
- 资产和旅行移除手机上多重嵌套白色边框，保留净额/当前行程主卡，扩大摘要与操作字号；旅行倒计时与准备进度成对排列。
- 阅读先显示继续阅读与书架，再显示每周阅读与笔记。沉浸阅读仍使用自己的布局与颜色。
- 自定义工作台突出近期任务，统一备忘、资料与设置列表。表单输入16px，主操作至少44px；保持抽屉内容滚动和底部操作区域。
- 修正801–900px旧桌面容器固定高度与手机布局交叉的问题，使用整页滚动。

验收覆盖360/390/430/820px五台，以及1440px桌面、空态/虚构示例/长标题、切台/主题/底栏/表单/阅读。浏览器触屏模拟不等于Android真机安装或软键盘实测。此次不修改原生Android代码和版本，更新网站后重新加载现有WebView即可获取UI。

验收与独立评审分别见 MOBILE_STUDIO_ACCEPTANCE.md、MOBILE_STUDIO_REVIEW.md；发布后证据见 MOBILE_STUDIO_RELEASE.md。
