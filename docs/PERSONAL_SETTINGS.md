# 个人设置跨工作台共用

日期：2026-11-04（Asia/Shanghai）。实现与协调：开发工程师 /root；独立评审 /root/settings_review；独立测试验收 /root/settings_qa。依据私人角色库及软件开发协作规范。

## 验收范围

- 昵称、关注目标和每日饮水目标在同一账号的健康、资产、旅行、阅读及自建工作台中共用；示例和个人空间也使用同一份个人设置。
- 任一入口保存后，顶部头像、问候、我的及账号安全页显示一致；账号安全页修改昵称也同步各工作台。
- 保存时清空旧切台缓存，重启后保留；不同账号仍独立。
- 网页、bootstrap、导出与 MCP get_settings/update_settings/get_today 使用同一来源。主题色及业务记录仍按工作台保存。

## 兼容升级

新增 personal_settings(owner,body)，按账号保存偏好。认证昵称直接读取 users.name；从个人设置更名时，在同一事务更新账号及偏好。旧分台 settings 表保留作升级参考。

首次读取继承健康个人空间的关注和饮水目标，不依赖首先访问哪个工作台。已登录账号以账号昵称为准，无账号本机版继承旧健康个人昵称；旧分台之间的冲突不合并，账号昵称和健康个人偏好优先。旧设置原文保留，不删除或改写。

昵称统一校验为1–80字符；饮水目标仍为100–10000毫升，非法请求不能部分更名。设置写入校验当前页面账号，会话在请求体读完后再次验证。
