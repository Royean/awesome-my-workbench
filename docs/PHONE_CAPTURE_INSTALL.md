# 手机采集使用说明

本次交付为工作台 0.7.3（703）安卓测试包，包名 `dev.awesome.myworkbench.debug`，会与正式版并行安装。需要工作台前后端部署同一功能版本，才能在网页查看和处理采集结果；本次开发交付不等于已经部署生产环境。

## 开启

1. 安装测试 APK，在工作台中登录自己的账号。
2. 打开应用右上角菜单「手机采集」，点击「绑定当前登录账号」。
3. 需要交易通知时，开启通知采集、勾选应用，并在系统授予通知使用权。安卓侧载应用如果提示受限，可在系统应用信息中查找「允许受限设置」，由用户自行授权。
4. 需要健康数据时，分别开启步数、睡眠、体重、静息心率或运动，授予对应 Health Connect 读取权限。运动距离另有独立开关。
5. 点击立即同步。后台健康读取仅在设备支持且单独授权时运行；其他设备在打开应用或手动同步时读取。

Android 9–13 需要可用的 Health Connect 独立应用；Android 14 及以上使用系统模块。手机、手表或健康应用必须把对应数据写入 Health Connect，本工作台才能读取。厂商健康应用的数据未连接时，不会凭空生成记录，也不会把无数据显示为 0。

## 结果

- **资产 → 流水 → 采集与待核对**：查看新交易通知，核对名称、日期、类型、金额和币种后保存流水，或忽略。重复金额只提供提示，账户余额和持仓不会自动调整。
- **健康总览**：显示最近步数；体重、睡眠和静息心率进入原有健康监测，运动进入运动记录。
- **我的 / 工作台设置 → 手机采集**：查看同步结果和来源，在安卓应用中管理手机权限。

所有日期按北京时间。步数同日替换而非累加，睡眠采用系统汇总并按结束日记录；体重和静息心率保留当日最新原始测量。运动使用有效运动时长，暂停不计；距离只在单独授权且有数据时提供。

运动仅使用一个来源，避免多个设备或应用重复记录同一活动。只有一个来源时自动选择；多个来源需在采集设置中选定。首次选择可读取最近七天，切换来源后仅同步切换后新开始的运动，已同步历史记录保留。

## 暂停和失败

可以暂停全部采集，或单独关闭应用和健康类型。关闭来源后，其本机旧队列也停止上传；关闭距离不会删除此前已同步的距离。账号切换、登录失效会暂停，重新绑定需要再次核对当前账号。

离线数据保存在应用私有队列，联网后重试；不会把旧账号数据发给新账号。队列上限为 2000 条，达到上限会显示错误，不静默淘汰旧数据。被服务器明确拒绝的数据会显示在拒绝数量中，可在设置清理；卸载会清理手机本地队列。

通知模板和厂商后台限制会影响采集覆盖，通知不包含历史账单和完整投资持仓。定期官方账单仍用于补漏和对账。真实手机通知、厂商后台和 Health Connect 有源数据读取的实测状态见[独立验收记录](PHONE_CAPTURE_ACCEPTANCE.md)。
