# 报告指标

报告现在可保存 observations 列表，最多 200 项。每项包含 label、code、result、unit、reference、flag；项目和结果必填，结果始终保存字符串以保留 <、>、阴性、负值等原始表达。只保留原报告标记（空、↑、↓、异常），不自动判断参考范围或生成诊断。不将检验或心电图参数冒充日常监测指标。

MCP create_record/update_record 支持报告字段 observations，list_records 返回完整列表。上传原件和关联报告仍通过原有专用工具。网页和 MCP 共享严格校验，旧表单未提交 observations 时保留原列表，显式 [] 才清空。旧文字报告继续可读，无数据库迁移。

报告列表显示指标数量；报告详情显示结果、单位、参考范围和原报告标记，手机上逐项卡片排列，并保留原文及原图入口。页面转义每个来源字段；未注明参考范围和未标记均显式显示，不解释为正常。
