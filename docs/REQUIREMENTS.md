# 个人健康工作台 v0.1

已确认：个人自用；融合就医、锻炼、饮食、监测；参考 TREK 的结构化管理与助手交互。
本次本地交付，不注册或部署云服务，不修改 TREK，不自动导入私人健康源仓库。

角色：产品协调及开发 /root；UI/UX /root/health_design；独立测试验收另行记录。

## 验收
- AC01 总览汇总四类数据，示例与个人空间严格分离。
- AC02 四类记录可新增、编辑、删除；字段验证；刷新和服务重启后保留。
- AC03 计划可新增、编辑、标记完成；支持按日期筛选。
- AC04 监测趋势只对同类同单位记录展示，血压分别呈现收缩压/舒张压，不标诊断阈值。
- AC05 文件可上传、下载、关联就医记录；限制文件类型与大小；不声称已OCR。
- AC06 搜索、导航、筛选、设置和助手入口可操作；无模型时明确未连接，支持从当前数据生成确定性记录摘要，不伪称AI。
- AC07 桌面和窄屏可用；表单有标签、错误反馈，删除支持撤销。
- AC08 仅本机监听，同源请求保护，用户输入作为文本显示，上传路径受控。

范围：本地单用户记录与展示；无医疗诊断/自动处方，无设备同步、远端MCP服务或云模型连接。示例数值均为虚构。

## v0.2 就医交互补全（用户反馈后扩展）

用户指出初版仅基础记录，缺少用药与就诊报告。已授权补全一次就诊的记录→报告→用药执行→复查流程；不改变个人本地使用范围。

- MED-AC01 就诊可填写医生、主诉、医生结论原文和医嘱，保留旧note；列表可进入详情并深链接刷新。
- MED-AC02 报告有分类、日期、来源、状态和原文，可就地上传/关联原件，预览PDF/图/TXT及下载；待补充/待核对/已归档状态明确。
- MED-AC03 用药方案记录药名、处方用量、途径、频次、指定时段或按需、起止日期与状态；不推算剂量。
- MED-AC04 逐时段记录实际服用时间或跳过原因，可更正、删除撤销；相同时段不得重复，停用方案不再生成待服事项，历史保留。
- MED-AC05 详情可新增关联复查任务，任务可完成并从计划列表返回对应就诊；原始资料在本次就诊内可上传/预览。
- MED-AC06 报告/附件/方案/服用记录的关联必须属于同一空间和正确类型；更新及撤销均保持关联一致，旧记录持久化兼容。
- MED-AC07 手机端详情、表单、服用操作可用，保存后留在本次就诊；示例数据明确虚构且个人空间不播种。

角色：产品协调/实现 /root；UI/UX审查 /root/health_design；独立测试验收及代码审查 /root/medical_review，分别记录证据。

## v0.3 高效快捷记录

用户明确选择优先降低记录负担，不优先做周日历和复杂计划。

- QUICK-AC01 首页上方四个入口：记一餐、记运动、记数值、传报告；时间默认填好，备注折叠选填。
- QUICK-AC02 饮食只需一句话、照片或原始录音之一；默认当前日期/时间及按时段选定的餐次，可修改；保留原话和原始媒体，不假装识别或转写。文字不超过5000字、最多4附件合计10MB，提交失败不留下半条记录。
- QUICK-AC03 运动选择项目+时长快捷值即可保存，最近的运动可填入；无需输入名称。
- QUICK-AC04 监测按项目直接输入数值，自动生成名称与单位，血压双值，不能预填上次测量结果。
- QUICK-AC05 报告原件无需就诊关联即可先传，以文件进入待整理；可筛选待整理/已关联，后续关联就诊建立报告；已整理原件进入已有报告避免重复创建。
- QUICK-AC06 照片可预览、录音可回放；麦克风授权失败可用其他方式记录，关闭抽屉停止录音释放资源。录音最长90秒；实际麦克风设备/浏览器能力按实测记录，模拟不冒称真机。
- QUICK-AC07 既有完整编辑、空间隔离、原始资料和持久化不回退；异步上传固定写入打开表单时的空间。桌面及390px可操作，核心数值框有可见焦点与标签。

实现 /root；设计审查 /root/health_design；独立测试验收及审查 /root/quick_capture_qa。

## v0.4 简约UI与布局

用户要求简约化，不扩展数据模型和业务流程。

- UI-AC01 浅色窄侧栏、单层页头，移除英文眉题、重复营销欢迎及整条示例横幅；顶部仍明确显示示例/虚构及AI未连接。
- UI-AC02 就诊使用紧凑行，保留标题、机构、日期、状态、关联数量以及详情/编辑/删除操作；详情四个区域不被隐藏。
- UI-AC03 首页只有一组快捷入口，指标合并分隔面板，移除重复快捷和装饰目标卡，当前关注目标仍显示于页头并可在设置编辑；最近记录默认4条。
- UI-AC04 桌面和390px下导航、搜索、空间切换、详情tab、快捷表单、焦点与关闭操作无回归；没有横向溢出。
- UI-AC05 字体与辅助信息保持可读，绿色用于主要动作及选择；手机用药管理按钮不拆行，图表刻度适配缩放。

本次仅静态UI改动，无后端/数据库变更。设计审查 /root/health_design，独立UI验收 /root/quick_capture_qa。
