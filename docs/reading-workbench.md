# 阅读工作台

关联：Refs #46 https://github.com/Royean/awesome-my-workbench/issues/46

## 范围与验收标准

新增独立的阅读工作台；保留健康、资产、旅行和自定义工作台。默认暖棕色 `#74634F`，可继续自定义。阅读数据按账号、工作台、个人/示例空间分别保存，不自动导入任何私人书单，不获取外部封面。

- AC01：新旧账号都能切换到阅读，刷新/重启后记录和自定义主题保持；不同账号/空间/工作台不可互相访问。
- AC02：书架支持书名、作者、想读/在读/读完/暂停状态、总页数和当前页；支持新增、编辑、进度更新、搜索筛选。未知页数保留未知，不计算伪造百分比；当前页不得超过已知总页。
- AC03：阅读记录与摘录必须关联同一空间书籍；支持日期、页码、分钟、引用原文与个人想法，按书籍及文本查询。记录页码不自动修改书架进度，避免部分成功；书架通过独立操作更新。
- AC04：阅读计划复用待办增改完成/取消完成；原件复用统一资料浏览、类型/日期/书籍筛选、PDF/图片/文本预览和缩略图，可选择或解除书籍关联。
- AC05：单项删除进入最近删除，30天可恢复；有阅读记录/原件关联的书籍不可直接删除，界面说明关联数量和处理方式；父书删除后恢复子记录需先恢复父书。
- AC06：手机单列书架、桌面多列，底部总览/书架/记录/摘录/我的；计划和资料可直接进入。表单错误保留输入，保存防重复，账号/空间/工作台切换会清空模块筛选状态并拒绝旧表单写入。
- AC07：MCP list/create/update/delete/restore 与原件上传查询都能使用阅读作用域，沿用既有写入确认与权限规则。

本次不含 EPUB 排版阅读器、电子书下载、外部书库搜书、OCR摘录、跨设备离线写入或阅读计时器；书封面为本地文字封面，上传的原件提供真实缩略图。

## 数据模型和行为

`reading_book`：title、date、note、author、status (wish/reading/finished/paused)、totalPages（未知可空，已知至少1）、currentPage（未知可空，非负整数）。

`reading_entry`：必须 bookId；title/date/note；entryType (session/excerpt)；page、minutes可空，分钟范围1–1440；quote可空，摘录类型至少填写原文或想法。阅读记录禁止未来日期，未来安排用阅读计划。

`file.bookId`：阅读空间中的可选关联。原件字节与现有上传/下载管道相同；更改关联不会修改原件。删除书籍采用引用阻止，避免隐式批量丢失阅读记录；不新增复杂级联迁移。

## UI 与交互

复用应用壳、抽屉、焦点保护、账号/工作台主题和原件预览。阅读画布浅暖灰、白色内容组、主题色书封面和进度条；列表正文/原文可换行。移动端保留两个二级入口“阅读计划/阅读资料”，不重复铺满一级导航。引用原文和个人想法有单独视觉标签。按压动效120ms，尊重系统减少动态效果。
