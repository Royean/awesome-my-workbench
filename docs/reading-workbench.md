# 阅读工作台

关联：Refs #46 https://github.com/Royean/awesome-my-workbench/issues/46

## 范围与验收标准

新增独立的阅读工作台；保留健康、资产、旅行和自定义工作台。默认暖棕色 `#74634F`，可继续自定义。阅读数据按账号、工作台、个人/示例空间分别保存，不自动导入任何私人书单，不获取外部封面。

- AC01：新旧账号都能切换到阅读，刷新/重启后记录和自定义主题保持；不同账号/空间/工作台不可互相访问。
- AC02：书架支持书名、作者、想读/在读/读完/暂停状态、总页数和当前页；支持新增、编辑、进度更新、搜索筛选。未知页数保留未知，不计算伪造百分比；当前页不得超过已知总页。
- AC03：阅读记录与摘录必须关联同一空间书籍；支持日期、页码、分钟、引用原文与个人想法，按书籍及文本查询。记录页码不自动修改书架进度，避免部分成功；书架通过独立操作更新。
- AC04：阅读计划复用待办增改完成/取消完成；原件复用统一资料浏览、类型/日期/书籍筛选、PDF/图片/文本预览和缩略图，可选择或解除书籍关联。
- AC05：单项删除进入最近删除，30天可恢复；有阅读记录/原件关联的书籍不可直接删除，界面说明关联数量和处理方式；父书删除后恢复子记录需先恢复父书。
- AC06：手机单列书架、桌面多列，底部总览/书架/记录/摘录/我的；计划和资料可直接进入。表单错误保留输入，保存防重复，账号/空间/工作台切换会清空模块筛选状态并拒绝旧表单写入。
- AC07：MCP list/create/update/delete/restore 与原件上传查询都能使用阅读作用域，沿用既有写入确认与权限规则。

本次不含 EPUB 排版阅读器、电子书下载、外部书库搜书、OCR摘录、跨设备离线写入或阅读计时器；书封面为本地文字封面，上传的原件提供真实缩略图。

## 数据模型和行为

`reading_book`：title、date、note、author、status (wish/reading/finished/paused)、totalPages（未知可空，已知至少1）、currentPage（未知可空，非负整数）。

`reading_entry`：必须 bookId；title/date/note；entryType (session/excerpt)；page、minutes可空，分钟范围1–1440；quote可空，摘录类型至少填写原文或想法。阅读记录禁止未来日期，未来安排用阅读计划。

`file.bookId`：阅读空间中的可选关联。原件字节与现有上传/下载管道相同；更改关联不会修改原件。删除书籍采用引用阻止，避免隐式批量丢失阅读记录；不新增复杂级联迁移。

## UI 与交互

复用应用壳、抽屉、焦点保护、账号/工作台主题和原件预览。阅读画布浅暖灰、白色内容组、主题色书封面和进度条；列表正文/原文可换行。移动端保留两个二级入口“阅读计划/阅读资料”，不重复铺满一级导航。引用原文和个人想法有单独视觉标签。按压动效120ms，尊重系统减少动态效果。

## 2026-11-02 阅读器调整

阅读导航收敛为书架、笔记。默认书架按书本/论文/文章/报告/其他分组；从书架导入 PDF、TXT、图片时，未指定已有材料则在同一事务内新建书架条目。旧资料仍可在管理入口关联。

PDF/TXT 阅读器恢复页码并保存翻页位置；PDF 支持缩放和提取本页文字，PDF/TXT 支持选中文字转为摘录笔记。TXT 每4000字符分页。扫描版PDF暂不提供OCR。当前不是完整微信读书替代品，尚无 EPUB、目录排版、持久文字高亮、全文搜索或在线模型回答。模型依用户要求稍后配置；qa 类型用于保存已有问题和回答。

实际执行：/root 实现导入事务、数据校验及整合；/root/reading_ui 实现书架导航与进度整合；/root/reader 实现阅读预览并独立检查导入事务及相关测试。自动测试不替代真实浏览器视觉验收；本轮未部署。

## 2026-11-03 逐首阅读与正文标注

识别已导入的唐诗/宋词TXT原文整理格式，目录搜索、逐首切换、单首一页；普通TXT继续按4000字符分页。无需改写线上原件。唐诗366篇、宋词280篇与源文件条目一致，不静默去重。

阅读器内选文划线、写笔记，reading_entry保存fileId/page/startOffset/endOffset/quote/annotationType/color；恢复标记时核对字符范围和原文，避免重名文字误定位。笔记可返回对应文件页与标注。PDF标注作用于提取文字区，未覆盖扫描OCR、PDF画布手写或完整微信读书功能。旧TXT页码切到逐首模式后按篇序解释，不能保证旧位置精确迁移。

## 2026-11-04 沉浸阅读

参考 Apple Books 官方阅读指南（https://support.apple.com/guide/iphone/read-books-iphc1af7c57/27/ios/27）的外观设置、按需显示控制方式。书架打开的阅读器默认铺满窗口，顶部书架返回、书名、字号、明亮/纸色/夜间主题；专注阅读隐藏界面控制，可从浮动入口恢复。浏览器支持时可显式进入原生全屏，失败保留整页阅读。字号主题仅保存在本机，不保存正文至偏好。

沿用对话框的焦点、Escape、账号切换和预览释放逻辑；其他工作台原件仍使用普通预览。正文保留目录、翻篇、选文划线、内联笔记；草稿使用既有放弃确认。桌面1440×1000、手机390×844隔离浏览器验证满屏、无横向溢出、外观、专注恢复、划线保存恢复和退出焦点。此段记录本地实现，尚未发布。

### 简体诗词与排版层次

已识别的唐诗/宋词合集默认以本地 OpenCC 1.3.1 转为简体显示，目录可按简繁文字检索。标题使用较大半粗无衬线字体，作者使用较小弱化无衬线字体，正文使用宋体。逐字转换保持 UTF-16 长度，罕见变长映射保留原字，防止既有标注范围漂移；保存引用仍取原始文本，显示转换不回写原件。第三方模块固定版本并随站点提供，许可证见 vendor/opencc-js/1.3.1。
